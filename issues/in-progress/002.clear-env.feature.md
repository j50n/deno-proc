# Start a child without the parent's environment

Every child inherits the whole environment, secrets included, and `env` only
adds to it. `Deno.Command` has `clearEnv`; proc doesn't pass it through.

Wanted: `clearEnv` on `ProcessOptions`, passed to `Deno.Command`. Found in the
pre-0.26.0 review (operator frame).

Where: `ProcessOptions` and the `Process` constructor (`src/process.ts`), which
picks the options it passes on by name.

Done: the option and its doc comment (with `env` it gives the child exactly
`env`; `PATH` included, so a bare program name may stop resolving), a line in
the book's Running commands page, a test that a variable set in the parent
doesn't reach the child.
