# A process's failure decision as one function

The stdout getter holds the library's error contract inline: `TimeoutError`
over `SignalError` over `ExitCodeError` over `UpstreamError`, then the
`fnError` rules. Every test of it spawns a child. From 008.

Decided: a pure function from the exit (status, timed out, upstream cause) to
the error, and one for handing it to `fnError`; the getter calls them.

Must not change: which error wins in each case, messages, `cause`, `fnError`
called only with an error or stderr data and never on an early stop, an async
`fnError` awaited.

Check: the suite; a table test of the precedence through the function.
