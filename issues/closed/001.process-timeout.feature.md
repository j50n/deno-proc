# A timeout for a child process

A hung child can only be stopped by hand today: `Deno.kill(p.pid)`. A cron job
or a service that runs commands needs a bound on how long one may take.

Wanted: an option on `ProcessOptions` (`timeoutMs`, or an `AbortSignal`, or
both) that sends the child SIGTERM when it runs out, so its consumer throws the
way it would for any kill. Found in the pre-0.26.0 review (operator frame).

Where: `ProcessOptions` and the `Process` constructor (`src/process.ts`),
`run()` (`src/run.ts`). The constructor passes only the options proc defines to
`Deno.Command`; this one is proc's own.

To decide: `SignalError` as for any kill, or an error that says the time ran out
(the program and the limit, not the arguments). What happens to a child that
ignores SIGTERM (proc never sends SIGKILL; `main` follows the same rule).
Whether `AbortSignal` is worth it next to a plain number.

Done: the option, documented on `ProcessOptions` and in the book (Running
commands, Errors); tests for a child that ends in time, one that doesn't, and
one stopped early before its time is up (no timer left running).

Decided (2026-10-06): a number only, `timeoutMs`; an `AbortSignal` can come if
someone needs one. A new `TimeoutError` (a `ProcessError`: the program and the
limit, never the arguments), thrown whenever the timer fired, however the child
then exited, since a run cut short didn't succeed and "killed by SIGTERM"
wouldn't say why. No SIGKILL, as in `main`. The timer runs from spawn to exit,
so it also bounds a child stopped early. NaN or negative: `RangeError` before
spawning. The whys are in `ProcessOptions.timeoutMs` and `TimeoutError`.

Closed by e45e347 "timeoutMs and clearEnv for child processes".

Verified: `tests/command/options.test.ts`: times out (well under the child's 5
s), a child that traps SIGTERM and exits 0 still throws, a child in time is
unaffected with no timer left (the test sanitizer checks), a child stopped early
is still stopped at the limit, NaN and -1 refused. None compile against 0.26.1,
which has no such option or error. Book example `processes/errors-timeout.ts`
checked against its output.
